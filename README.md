# 📊 Painel de Atendimentos

Painel web para controlar agendamentos de atendimentos, acompanhar pendências e visualizar indicadores do mês.

🔗 **Acesse online:** https://isaac-andrade07.github.io/painel-atendimentos/

A ideia nasceu de um problema real: controlar atendimentos com anotações soltas faz com que agendamentos sejam esquecidos. O painel reúne tudo em um só lugar e mostra rapidamente o que precisa de atenção.

## ✨ Funcionalidades

- Cadastro de atendimentos com cliente, serviço, data, hora e equipe
- Indicadores do mês: recebidos, falta agendar, sem equipe, agendados e concluídos
- Gráfico de atendimentos por dia
- Alertas de atendimentos vencidos e de atendimentos do dia ainda sem equipe
- Busca e filtro por status
- Exportação para CSV (abre direto no Excel)
- Dados salvos no próprio navegador, sem precisar de servidor

## 🛠️ Tecnologias

- HTML5
- CSS3 (Grid, Flexbox e layout responsivo)
- JavaScript puro (Canvas para o gráfico e localStorage para salvar os dados)

## ▶️ Como usar

Acesse a versão online pelo link acima ou baixe o repositório e abra o arquivo `index.html` no navegador.

Para ver o painel funcionando com dados, clique em **Carregar exemplo**.

## 📁 Estrutura

```
index.html   → estrutura da página
style.css    → visual e responsividade
script.js    → regras, indicadores, gráfico e armazenamento
```
